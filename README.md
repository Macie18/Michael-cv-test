# Michael-cv-test

马乃东律师双语个人网站，包含中文站与 `/en/` 英文站。

仅包含已整理的网站页面、网页资源、文章题录与简历/联系人下载文件。原始 Word、PowerPoint、内部工作文档及任何登录凭据不在此仓库。

文章全文版权归原作者及发表平台，点击卡片到原平台阅读。未取得链接的记录标注为文献信息；有原文封面的显示原文封面；无封面的使用文字链接预览，不使用网页截图或局部滚动。

使用 GitHub Pages 从 `main` 分支根目录发布预览，并可将同一份文件直接部署到阿里云香港 OSS。无后端、无构建步骤、无云密钥依赖。

正式域名为 `https://naidongma.com/`。页面已配置 canonical、双向 `hreflang`、结构化数据、`robots.txt`、`sitemap.xml` 与 `llms.txt`。OSS/CDN、HTTPS、DNS 和搜索引擎提交步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)。
